## ZUI_AB_LIBR_DRAW

AB - Drawing reuse component. A self-contained SAPUI5 drawing board (canvas) that can be
embedded as a Smart Templates / Fiori Elements reuse component, modelled after
`ZUI_AB_LIBR_SIGN`. The drawing feature (pen / line / rectangle / circle / select / pan
tools, preset objects, zoom, undo, clear and JPG export) is ported from the `sapui5drawing`
project.

### Starting the generated app

-   Launch the app from the project root:

```
    npm start
```

-   Or run standalone (no Fiori Launchpad sandbox):

```
    npm run start-noflp
```

#### Pre-requisites:

1. Active NodeJS LTS (Long Term Support) version and associated supported NPM version.  (See https://nodejs.org)
